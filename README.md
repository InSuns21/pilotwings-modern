# Pilotwings Modern

TypeScript、Vite、Three.js、Rapier WASM で構築した、ブラウザ向け3Dフライトゲームです。

起動するとスタート画面が表示され、以下を選んでからフライトを開始できます。

- WORLD: 「トレーニング・アイランド」と「松本リアル・テレイン」の2種類。後者は国土地理院の航空写真タイルとDEMを使い、実在の松本空港RWY 18/36へ座標・方位・実寸を合わせたリアル地形ワールド
- AIRCRAFT: 現在は「TR-01 練習機」1種類
- TASK: WORLD × AIRCRAFT ごとに対応タスクを切り替える。TR-01では島の「基礎操縦サーキット」「地上ターゲット射撃訓練」と松本の「松本パターン訓練」を用意

AIRCRAFTは現在TR-01のみですが、TASKはWORLDとAIRCRAFTの互換条件を持つカタログ構造です。WORLDまたはAIRCRAFTを変えると、その組み合わせで実行できるTASKだけが表示されます。スタート画面ではワールドと機体をThree.jsの実3Dプレビューで確認でき、タスクは操作課題が分かる経路図で確認できます。機体プレビューは本編と同じ `AircraftModel` を直接使用します。フライト中は `TITLE` からスタート画面へ戻れます。

「松本リアル・テレイン」は国土地理院の「全国最新写真（シームレス）」を地表テクスチャとして使い、標高タイル（DEM5Aを優先し、欠損時はDEM10B）から地形メッシュを生成します。広域地形は軽量なベースとして保持し、飛行中は機体周辺に z16、そのさらに近傍に z18 の航空写真タイルを追従ロードして低空時の地表解像度を上げます。高解像度レイヤは常時全域を読み込まず、各段階5×5タイルだけを保持します。RWY 18/36は公開されている閾値座標と真方位をローカル座標系の基準にし、2,000 m × 45 mの実寸で航空写真上の滑走路へ重ね、舗装・エッジ・センターライン・しきい値マーキングを同じ座標系で手続き生成します。現在の飛行モデルは平坦滑走路を前提とするため、写真の位置は変えず、滑走路直下のDEM標高だけを周辺地形へ滑らかにつなぐ airport flatten を行います。

スタート画面の `HEIGHT EXAGGERATION` でDEM地形の高さを1.00〜3.00倍に調整できます。松本リアル・テレインは実行時に地理院タイルを取得するため、ネットワーク接続が必要です。画面右下に出典を表示します。

現在プレイできるタスクは、8リングの操縦訓練と、3標的の地上ターゲット射撃訓練です。

- トレーニング・アイランド × TR-01「基礎操縦サーキット」: 離陸上昇 → 水平化 → ROLLによる旋回 → 高度・速度維持 → PATHを使った降下 → 滑走路整列 → フレア着陸
- トレーニング・アイランド × TR-01「地上ターゲット射撃訓練」: 離陸し高度18〜120mで機首を地上標的へ向け、3つの標的を順番に射撃。旋回・再進入しながらすべて命中すればクリア（実在の建物や滑走路を標的にはしません）
- 松本リアル・テレイン × TR-01「松本パターン訓練」: 空港スケールの上昇 → 周回旋回 → 滑走路と平行な水平飛行 → 降下 → 最終旋回 → 再進入 → 着陸

射撃訓練では F キーまたはタッチの FIRE ボタンで単発射撃します。標的は地面に寝かせた円ではなく、視認しやすい大型の直立式パネルです。命中判定は表示されたパネルの面に一致します。チェイスカメラの中央レティクルとは別に射線と標的面の交点へ GUN SIGHT を投影し、照準が合うと ON TARGET · FIRE を表示します。HIT / MISS、SHOTS、HIT数も表示します。飛行モデルの失速・衝突・過速度の安全判定は同じです。標的は専用の非人物ターゲットで、射撃のゲーム内演出だけを行います。

リング通過後・標的命中後は、達成済みオブジェクトが3Dワールドと索引図から消え、次の目標を探しやすくなります。いずれのタスクでも、画面右側に速度計・姿勢指示器（PITCH/BANK）・方位計・全体索引図を表示します。索引図には機体位置と向き、残りのリングまたは標的、滑走路を表示します。島の方位はローカル相対方位（+X=000°）、松本の方位は真方位です。\n\nリング訓練では次リングのHUDメッセージに、PITCH / ROLL / PATH / BRAKEなどその区間で意識する操作を表示します。リング面も前区間からの進入方向へ向くため、単なる点通過ではなくコースとして読み取れる構成です。

危険な飛行状態は、単に見逃すのではなくゲーム上の失敗要素として扱います。

- 低速・高迎角の失速では操舵性が低下し、機首が下がり、降下が強くなる
- 約50 km/hは失速境界ぎりぎりではなく、明確に失速域に入る
- 失速からの回復には、十分な速度回復と機首下げが必要
- 過度な機首上げ姿勢では、失速前後に警告を表示する
- 水平飛行では約187 km/h付近で推力と抗力が釣り合うが、降下では高度を速度へ交換してそれ以上へ加速できる
- 250 km/hからOVERSPEED警告を表示し、最大降下速度280 km/hを超えると機体限界超過として飛行終了
- 山や地面への衝突で飛行終了
- 滑走路外への着地で飛行終了
- 着陸速度、バンク、降下率、危険な接地姿勢が限界を超えると飛行終了。ただし通常の機首上げフレアは許容する
- 墜落時は飛行を停止し、失敗理由付きの GAME OVER を表示する

## 開発

```bash
npm install
npm run dev
```

PC操作:

- `↑ / ↓`: ピッチ上げ / 下げ
- `A / D`: 左 / 右ロール
- `Q / E`: 左 / 右ヨー
- `Space`: 押している間 THRUST
- `Shift`: 空中ではエアブレーキ、滑走路上ではホイールブレーキ
- `F`: 地上ターゲット射撃訓練のみ、単発射撃
- `RESTART MISSION`: 機体とミッション進行をリセット

タブレット / タッチ操作:

- 左バーチャルスティック: ピッチ / ロール
- `YAW ◀` / `YAW ▶`: ヨー
- `THRUST`: 押している間推力を加える
- `BRAKE`: 空中ではエアブレーキ、接地後はホイールブレーキ
- `FIRE`: 地上ターゲット射撃訓練で単発射撃
- マルチタッチ対応

飛行モデルは操作しやすいアーケード寄りですが、現在は機体姿勢と実際の飛行経路を分離しています。HUD の `PITCH` は機首の向き、`PATH` は実際の上下方向の飛行経路角です。これにより、`PITCH +8〜+14°` でも `PATH` と垂直速度がまだマイナスという、着陸時のフレアが成立します。

THRUSTを離して操作を中立にすると、速度を失い続けるのではなく、約80 km/h前後の浅い滑空へ自然に落ち着きます。BRAKEは通常の抗力とは別の追加減速として働き、接地後はより強いホイールブレーキになります。

THRUSTは意図的にON/OFFの2値操作のままです。現在の基本仕様では段階式・アナログスロットルは採用していません。

機体モデルは箱を組み合わせた仮モデルではなく、オリジナルのローポリ練習機です。先細りの胴体と主翼、キャノピーとパイロット、尾翼、固定脚、翼端灯、排気管、3枚プロペラ、速度連動のプロペラブラー、影表現を備えています。
